# Implementation coverage

This matrix reconciles the supplied PRD with the 1.4.0 refinement. **Implemented** describes working source behavior; test evidence is separately recorded in [TEST_REPORT.md](TEST_REPORT.md). **Limited** means meaningful functionality exists with stated boundaries. **Conditional** means a browser, account, endpoint or external service is required. **Future / absent** is not represented as a working feature.
